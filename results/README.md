# Results Layout

## `main_results/`

Packaged outputs for the original connectome-vs-random comparisons and the lightweight mechanism
summaries used in the paper.

## `revision_results/`

Packaged outputs for the corrected control ladder:

- random-initialization control
- degree-preserving null
- degree-preserving ensemble summaries
- initial-activity diagnostic

## `tables/`

Lightweight CSV tables used in figures and paper summaries.

## `generated/`

Recommended destination for fresh reruns launched from the wrapper scripts in [`scripts/`](../scripts).
